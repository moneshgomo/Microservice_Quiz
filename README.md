# BackendIQ — Microservices Quiz Application

<br>

A microservices-based Quiz Application built with Spring Boot, containerized with Docker, and deployed on Kubernetes (KIND). Built as a solo college mini project. 

> 🚧 Project is 80% complete and actively in progress.


<br>

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Java, Spring Boot |
| API Routing | Spring Cloud Gateway |
| Service Discovery | Netflix Eureka |
| Frontend | React (Vite) |
| Database | MySQL (Aiven Cloud) |
| Containerization | Docker |
| Orchestration | Kubernetes (KIND) |

<br>

## What's Done

- [x] 3 Spring Boot microservices — Quiz Service, Question Service, API Gateway
- [x] Eureka Service Registry for service discovery
- [x] REST APIs for quiz and question management
- [x] React frontend for taking quizzes
- [x] Dockerized all services and pushed to Docker Hub
- [x] Kubernetes manifests — Deployments, Services, ConfigMaps, Secrets
- [x] Deployed and running on KIND cluster locally

<br>

## What's Pending

- [ ] CI/CD pipeline — auto push Docker images to Docker Hub on push to main branch
- [ ] RabbitMQ — async messaging between services
- [ ] User Service + OAuth2 — authentication and authorization
